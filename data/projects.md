# My projects

## Skin disease detection app (Final Year Project)
My final year project is a skin disease detection app that covers 5 to 6 conditions. It uses the Kaggle DermNet and HAM10000 datasets. The core deliverable is a working app where a user uploads a photo, gets a prediction with a confidence score, can flag a case for a doctor, and can see their scan history. Instead of trying to beat existing accuracy benchmarks, my group is focusing on a deployable app, evaluation broken down by skin tone, and a Pakistan-specific context. Earlier, my group explored manhole and open cover detection, because there is no Pakistan-specific dataset and existing models do poorly on the open or missing class. We moved away from it because our advisor preferred a development-heavy project.

## MindBridge-RAG
MindBridge-RAG is a group project for my cloud computing course: a RAG chatbot for focus and concentration topics. The first version (S1, basic RAG) was tested and got perfect scores in human evaluation. The second version (S2, safety-aware RAG) has not been tested yet. I built the evaluation CSV files and a presentation deck covering the full pipeline.

## Task Manager app (MAD final project)
A mobile app built with React Native, Expo Router and TypeScript, with Supabase as the backend. It uses the OpenWeather API with Pakistani cities, has six database tables and two user roles.

## Calorie Tracker (HCI and MAD)
An 8-screen Expo React Native and TypeScript app. For the HCI course I also built an interactive HTML prototype and documented the design using Fitts's Law, Hick's Law, Nielsen's heuristics and Gestalt principles, and upgraded the project from Expo SDK 52 to 54.

## MCCU (Mini Compiler Construction Unit)
A SQL-focused mini compiler project for my compiler construction course. I presented the tokenizer module, explaining it in Roman Urdu.

## Local LLM with LM Studio (Agentic AI course)
For my Agentic AI Systems and Applications course I installed LM Studio and ran the Nemotron 3 Nano 4B model (GGUF, Q4_K_M, 2.84 GB) locally on my laptop, which has about 6 GB of RAM and no powerful GPU. I tested it through the local API on port 1234 with a Python script. Replies were slow because everything runs on the CPU, which is why I chose a small 4B model.
